Шаг 2 — создай Release и прикрепи зипы.

Перейди по адресу: https://github.com/neznaeva/ozon/releases/new
(или вверху репо справа найди Releases → Draft a new release).
Choose a tag → впиши data → нажми всплывающее «Create new tag: data on publish».
Заголовок (Release title) — любой, например WB Ozon выгрузки.
Внизу есть область «Attach binaries by dropping them here or selecting them» — перетащи туда зип-файлы (WB и Ozon). Дождись, пока каждый дозагрузится (большие — минуту-другую).
Нажми зелёную Publish release.
